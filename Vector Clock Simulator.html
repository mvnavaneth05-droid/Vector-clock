Algorithm

  • Local event (Pi): VC[i] = VC[i] + 1
  • Send (Pi → Pj): VC[i] = VC[i] + 1, then message-oda VC attach pannitu anuppum
  • Receive (Pj): VC[k] = max(VC[k], msgVC[k]) for all k, then VC[j] = VC[j] + 1
  • a → b (happened-before) iff VC(a) ≤ VC(b) in all positions and VC(a) ≠ VC(b)
  • a ∥ b (concurrent) iff neither VC(a) ≤ VC(b) nor VC(b) ≤ VC(a)
